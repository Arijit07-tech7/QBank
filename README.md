# 🚀 About QBANK

**QBANK — Academic Archive** is a clean, fast and modern frontend-based academic question-paper archive designed to make previous-year question papers easier to discover and access.

Instead of searching through random folders, files or chat groups, QBANK provides a structured academic navigation system.

### The experience is simple:

```text
🎓 Department
      ↓
📅 Academic Year
      ↓
📖 Semester
      ↓
📚 Subject
      ↓
📄 Question Paper
      ↓
👁️ View / ⬇️ Download
